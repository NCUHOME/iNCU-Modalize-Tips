# 路由文档写作规范

本 skill 只管 `page.tsx` 的 **内容怎么写**。创建新分类或页面骨架时，查阅 [`docs/CLI.md`](../../../docs/CLI.md) 获取 `pnpm cli` 命令，先用 CLI 建骨架再按本文规范填充内容。

严禁阅读 CLI 代码或 template，只允许调用 CLI 生成骨架。

> **权威参考：**
>
> - `app/routes/add-widget-guide/ios/page.tsx` — guide 类，多段落、插图、版本提示、`<Gallery>` 全覆盖

## guide vs troubleshoot vs 其他分类

|              | add-widget-guide                 | widget-troubleshoot                           | 其他分类                                                                                                                          |
| ------------ | -------------------------------- | --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| 首段 `<h2>`  | `操作步骤` 或 `添加主屏幕小组件` | `检查步骤`                                    | 描述核心操作的名词短语                                                                                                            |
| 后续 `<h2>`  | —                                | —                                             | 按功能模块命名（如"App 图标快捷菜单""小组件快速交互"），每个 `section` 讲一个独立操作                                             |
| 步骤格式     | 纯文字 `<li>`                    | `<strong>小标题</strong>` + `<p>路径描述</p>` | 操作步骤用 `<ol>`，选项列举用 `<ul>`（见下方"独立 `<ul>` 列举选项"规范）                                                          |
| 路径风格     | 在哪里找 → 怎么点 → 怎么拖       | 设置 → 应用 → 电池 → 权限开关                 | 同 guide                                                                                                                          |
| 图标快捷菜单 | —                                | —                                             | 若页面涉及图标长按 / Haptic Touch / 3D Touch 菜单，h2 命名为 `App 图标快捷菜单`，用 `<ol>` 描述触发方式，用独立 `<ul>` 列举各选项 |

## 文本规范

| 元素         | 写法                                               |
| ------------ | -------------------------------------------------- |
| App 名称     | `<strong>南大家园</strong>`                        |
| UI 按钮/标签 | `<strong>小组件</strong>`、`<strong>编辑</strong>` |
| 系统功能名   | `<strong>应用速冻</strong>`                        |
| 导航路径     | `设置 → 应用 → 电池`（`→` 前后各一个空格）         |
| 选项值       | 中文双引号：`选择"无限制"`                         |
| 插图前换行   | `<br />` 放在图片上方                              |

## `<Image>` / `<Gallery>`

```tsx
// 单图 — 放在步骤文字之后，<br /> 隔开
<Image src={img} alt="描述" caption="图注" maxWidth={300} />

// 对比图 — maxWidth=200 并排
<Gallery>
  <Image src={a} alt="浅色" caption="浅色" maxWidth={200} />
  <Image src={b} alt="深色" caption="深色" maxWidth={200} />
</Gallery>
```

- 图片统一 `.webp`，放在 `./image/` 目录下
- `alt` 必填，`caption` 可选，`maxWidth` 默认 400

**没有图片时：** 如果页面目录下没有 `image/` 文件夹或其中没有 `.webp` 图片文件，则**完全不插入图片相关代码** —— 不要写 `import`、不要写 `<Image>` / `<Gallery>`、不要留 TODO 占位。步骤纯文字即可，等有实际截图后再补。

## 嵌套子步骤 vs 独立 `<ul>` 列举选项

有两种使用 `<ul>` 的场景，规则不同，先判断属于哪一种再决定写法：

### 场景 A：嵌套子步骤（`<ul>` 放在 `<li>` 内部）

重要且难理解的步骤必须使用 `<ol>` 分点方便随时插入图片，不准写为嵌套子步骤；易于理解的繁多步骤（如设置页的路径）可以写作嵌套子步骤。

展开同一操作下不同版本或分支路径时使用，**必须加** `className="list-outside list-disc"`，否则圆点消失：

```tsx
<li>
  <strong>允许自启动</strong>
  <ul className="list-outside list-disc">
    <li>ColorOS 12及以上：设置 → 应用 → 自启动 → ...</li>
    <li>ColorOS 7 - 11.3：手机管家 → 权限隐私 → ...</li>
  </ul>
</li>
```

**注意：** `<ul>` 必须放在 `<li>` 内部，不能放在 `<ol>` 之后作为独立列表。否则 HTML 结构错误——子选项变成了独立列表而非步骤的一部分。

### 场景 B：独立 `<ul>` 列举选项（`<ul>` 放在 `<ol>` 之后）

当步骤完成后需要展开选项（如"根据需要选择以下选项"、快捷菜单的功能介绍），且各选项**不是同一操作的不同路径**，而是并列介绍时，使用独立 `<ul>`：

```tsx
<ol>
  <li>长按 <strong>南大家园</strong> 图标</li>
  <li>根据需要选择以下快捷选项：</li>
</ol>
<ul className="list-outside list-disc">
  <li><strong>我的课表</strong>：快速打开课表页面</li>
  <li><strong>我的成绩</strong>：快速进入成绩查询</li>
</ul>
```

**规则：**

- 独立 `<ul>` 紧跟在 `<ol>` 关闭标签后，前面**不需要也不应该**套一层 `<li>`
- **必须加** `className="list-outside list-disc"`
- 语义上仍属于该 `section` 的内容，在 h2 结构上是合理的
- 独立 `<ul>` 与嵌套子步骤的区别：前者是"操作完成后列举选项"，后者是"某一步操作下的分支路径"

## section 内提示

放在 `<h2>` 正下方，固定样式：

```tsx
<p className="-mt-2 mb-1 text-neutral-600" style={{ fontSize: "12px" }}>
  <strong>iOS 16</strong>及以上版本支持在锁屏界面添加小组件。
</p>
```

也可放在 section 末尾充当全局提示。

---

## 结尾：注意事项

**有注意事项的页面必须以「注意事项」`<section>` 结尾：**

```tsx
<section>
  <h2>注意事项</h2>
  <ul>
    <li>不同品牌Android系统界面可能略有差异，请以实际为准</li>
    <li>如果以上方法无效，请查看对应品牌的指南</li>
  </ul>
</section>
```

- 通用品牌（android）：提示品牌差异 + 引导查看具体指南
- 具体品牌：提示该系统版本差异
- iOS：提示最低版本 + App 更新

## 输出前必验

- [ ] 每个 `<section>` 有且仅有一个 `<h2>`
- [ ] 步骤用 `<ol>`，注意事项用 `<ul>`
- [ ] `<strong>` 包裹 App 名、UI 按钮、系统功能名
- [ ] 路径用 `→`（前后空格），选项值用中文双引号
- [ ] 每个 `<ul>` 都有 `className="list-outside list-disc"`（无论是嵌套还是独立）
- [ ] `<ul>` 位置正确：嵌套子步骤在 `<li>` 内，独立选项在 `<ol>` 后
- [ ] 有图片文件才插入 `<Image>` / `import`；没有则不写
- [ ] 最后一个 `<section>` 是「注意事项」
- [ ] 版本提示用固定 `className` + `fontSize`
- [ ] `export default function` 组件名语义化
